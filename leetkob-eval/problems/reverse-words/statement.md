# Reverse every word

Read one line of words and print it with every word reversed, keeping the words in their
original order.

## Input
One line of at most 100 000 characters: lowercase words separated by single spaces, no leading
or trailing space, at least one word. Each word has at most 100 letters.

## Output
The same line with every word reversed.

## Example
Input
```
hello world
```
Output
```
olleh dlrow
```

## Limits
Time limit: 2 seconds. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
