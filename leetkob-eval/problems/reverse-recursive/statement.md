# Reverse and sum without loops

Read `n` integers. Print them in reverse order, then print their sum. This lab practises
recursion: the program must not contain any loop.

## Input
- Line 1: `n` (1 ≤ n ≤ 1000).
- Line 2: `n` integers `a_i` (|a_i| ≤ 10^6).

## Output
- Line 1: the `n` integers in reverse order, separated by spaces.
- Line 2: the sum of the integers.

## Example
Input
```
5
1 2 3 4 5
```
Output
```
5 4 3 2 1
15
```

## Limits
Time limit: 2 seconds. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
