# Sorting with merge sort

Read `n` integers and print them in non-decreasing order.

## Input
- Line 1: `n` (1 ≤ n ≤ 5000).
- Line 2: `n` integers `a_i` (|a_i| ≤ 10^9), separated by spaces.

## Output
One line: the `n` integers in non-decreasing order, separated by single spaces.

## Example
Input
```
6
5 -2 9 -2 0 7
```
Output
```
-2 -2 0 5 7 9
```

## Limits
Time limit: 2 seconds. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
