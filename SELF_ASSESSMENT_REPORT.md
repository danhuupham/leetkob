## What we did not manage

- **Earlier mixed-part commits in `PA#3` git history (Criterion 7):** Commits `fe9d16a` (28 files before merge-forward discard), `a803b3d`, `07acedc`, and `111f7c1`/`fa68bc0` (7s apart) remain in the `pa3` history because rewriting timestamps or splitting commits retroactively violates the rubric. All post-review fixes ([PR #22](https://github.com/danhuupham/leetkob/pull/22)–[PR #26](https://github.com/danhuupham/leetkob/pull/26)) strictly followed one-part-per-PR test-first discipline.
- **Committed dev run missed 1 disguised semantic violation:** In [`eval/runs/pa3-dev/report.txt`](eval/runs/pa3-dev/report.txt), `dynamic-array/s05 C2 [disguised]` was predicted `pass` (`97.3%` recall `36/37`, `0` wrongful deductions), left un-tuned to avoid problem-specific prompt rules ahead of `PA#4`.
- **Custom eval cases reuse dev-set problem texts:** `eval/custom-cases/` currently tests 6 new C++17 solutions against copied `sort-merge` and `binary-search` statements; adding brand-new custom problem statements and constraints is queued for `PA#4`.
- **Milestone-deferred features (`PA#4`/`PA#5`):** `10%` random `pass` queue sampling (`FAQ-10`), post-publish constraint appeals (`FAQ-13`–`FAQ-14`), TA manual mark input for non-`AC` submissions in UI (`FAQ-04`), and live student/constraint editing flows are scoped for `PA#4`–`PA#5`.
- **Admin bypass during PR stack merge:** `enforce_admins` on `main` branch protection was temporarily disabled (`enforce_admins: false`) solely to merge the approved PA#3 PR stack cleanly with CI green.

## What we would do differently

- Standardize one target Gemini model ID (`MODEL_NAME`) across `src/config.js`, `README.md`, and live eval runs early so unit tests and deployment defaults share the exact same model string without per-environment overrides.
- Land PR #18 (`T3.1` worker/queue) and PR #13 (`T3.4` model/limits) into `main` earlier so downstream UI integration (`T3.6`) does not accumulate diverged copies of upstream modules before merge-forward reconciliation.
